## Overview

This Arduino project uses the Cirque library to read raw capacitive measurements from a Gen6
device running the CustomMeas firmware. It does not use the device as a touchpad.

This code requires the Teensy 4.0 have its USB set to "Serial".

Reference the document Interfacing to CustomMeas, GP-AN-191113
